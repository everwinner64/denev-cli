The Denev Website uses PostHog in cookieless mode to collect basic, anonymous usage statistics. Analytics are limited to a small set of manually defined events, such as page views and download actions. No advertising, no session replay, no cross-site tracking. You can review PostHog's privacy policy here: https://posthog.com/privacy

The Denev CLI contains no analytics or telemetry and sends no usage data. It runs locally and only makes network requests when checking for updates or when a command explicitly requires network access, such as HTTP requests or distant certificate operations.

If you have any questions about this policy, you can get help by opening an issue on the [GitHub repository](https://github.com/everwinner64/denev-cli/issues/new/choose).
