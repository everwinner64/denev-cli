# Security Policy

## Scope

This policy applies to all official Denev projects, including:

* The `dnv` CLI
* The official documentation and website
* Official installation scripts

## Supported Versions

Only the latest stable release is supported.

Older releases are considered end-of-life (EOL) and **will not receive security updates**.

## Reporting a Vulnerability

> [!IMPORTANT]
> **Do not report security vulnerabilities through public GitHub issues or pull requests.**

Instead, use **GitHub Private Vulnerability Reporting**:

**Repository ➜ Security ➜ Report a vulnerability**

When possible, include:

* A description of the vulnerability
* The affected component
* The affected version (if known)
* Your OS/Environment
* Steps to reproduce the issue
* The potential impact

A proof of concept is appreciated, but not required.

All reports are handled privately through GitHub Private Vulnerability Reporting.

## Security Updates

Confirmed vulnerabilities are fixed as soon as reasonably possible and released in the latest stable version only.

Users are encouraged to keep Denev up to date to receive security fixes.
